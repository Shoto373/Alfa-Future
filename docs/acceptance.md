## Найденные и исправленные дефекты

1. Пустой элемент XML ложен в `bool`, из-за этого RSS-парсер терял описание новости. Исправлено явной проверкой на `None`, добавлен тест.
2. «Ужесточение» кредитования классифицировалось как рост, и автодилеру показывалась «возможность». Теперь направление определяется по каждой теме отдельно, ужесточение кредита считается направлением `down`.
3. Нормализация чисел в самопроверке склеивала соседние числа («4К26 3–6» → «4К263–6»), из-за этого удалялось корректное действие. Убираются только пробелы-разделители тысяч, добавлен тест.
4. Стемминг из 6 букв не связывал «ставку» и «ставка» в поиске по базе знаний. Стемминг уменьшен до 5 букв.
5. Интерфакс и Коммерсантъ отвечают редиректом 301. Добавлено ручное следование редиректам с SSRF-проверкой каждого адреса.
6. Новости RSS без бизнес-тем (политика, спорт) засоряли ленту. Теперь они отсеиваются при сборе.

- Браузеры кроме Chromium, реальные мобильные устройства.
