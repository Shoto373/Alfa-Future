# План работы: «Альфа.Пульс» — новостная аналитика для крупного бизнеса

Основа: кейс «Новостная аналитика для принятия бизнес-решений» (Альфа-Банк × Changellenge), дедлайн 26.10.2026.
Отправная точка: каркас спринта 1 (FastAPI + Next.js + Docker + прод на pointers-team.online).

## Цель

Сервис в интерфейсе Альфа-Бизнеса, который:

1. определяет бизнес-контекст компании по данным кейса (отрасль, масштаб, доля в выборке, продукты банка, ВЭД, группа, контрагенты по платежам);
2. собирает новости (парсер RSS + ручное добавление), классифицирует их и извлекает ключевые факты;
3. ранжирует новости под конкретную компанию и роль пользователя, объясняя причины релевантности;
4. агентно готовит персонализированную интерпретацию: что произошло → почему важно → риски и возможности → действия → позиция Альфа-Банка → на чем основан вывод;
5. дает задать уточняющий вопрос, перейти к первоисточнику, оценить ответ;
6. трассирует шаги агента, логирует обращения к инструментам и собирает метрики качества.

## Ограничения, которые учитываем

- Разрешены только LLM из Приложения 3 (Gemma 4 26B A4B, GLM-5.3-Flash, Qwen3.6 35B A3B, DeepSeek-V4.1-Flash, Qwen3-VL-30B-A3B-Instruct, Kimi-K2.6). Ключ подключается позже → backend имеет allowlist моделей и полноценный **режим без LLM** (детерминированный агент на правилах), чтобы сценарий проходился уже сейчас.
- Не готовая мультиагентная система: агентную логику (план → инструменты → контекст → самопроверка → коррекция) пишем сами.
- Позиция банка — только из материалов Альфа-Банка с цитатой (документ + страница). Выводы модели помечаются отдельно.
- Данные кейса (CSV, PDF) не коммитятся: в репозитории синтетический набор той же схемы, реальные данные монтируются через `DATA_DIR`.
- Работа с неполными и зашумленными данными: `null` = «неизвестно», выбросы выручки, отсутствующие ОКВЭД/регион.

## Этапы

| # | Этап | Результат |
|---|---|---|
| 1 | Анализ задания и данных | профиль датасета, критерии отбора крупного бизнеса (> 15 млрд ₽) |
| 2 | База знаний банка | структурированные тезисы 9 материалов ЦМА (тема, отрасли, цифры, страница) |
| 3 | Профили компаний | скрипт ETL: признаки, доля в отрасли выборки, группа, контрагенты, связи через физлиц, «экспозиции» к факторам |
| 4 | Новости | парсер RSS, ручное добавление (текст/URL), классификатор тем/отраслей/стран, извлечение фактов, дедупликация |
| 5 | Ранжирование | скоринг «новость × компания × роль» с объяснимыми факторами |
| 6 | Агент | LLM-клиент (OpenAI-совместимый, allowlist), инструменты, план, контекст, самопроверка, трасса, аудит |
| 7 | API | профили, лента, инсайт, вопрос, источники, обратная связь, метрики |
| 8 | Интерфейс | Альфа-Бизнес: вход под демо-пользователем, главная с точкой входа, лента, карточка инсайта, трасса, чат, метрики |
| 9 | Проверка | unit, API, e2e smoke, UI в Chromium |
| 10 | Деплой и документация | сервер, README, THIRD_PARTY_NOTICES, отчет в Word |

## Метрики качества (мониторинг)

- контент: доля карточек, прошедших самопроверку с первой попытки; доля выводов со ссылкой на источник; число фактических расхождений (числа в выводе, которых нет в источниках);
- персонализация: CTR ленты, доля «полезно» по карточкам, nDCG по оценкам экспертов на контрольной выборке;
- AI: латентность шагов, токены/день против лимита, доля fallback на правила, доля повторов самопроверки.
